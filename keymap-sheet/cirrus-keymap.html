Base

Normal typing. Colored keys lead to the other layers (colors match the status light).

Layer Lock

TAP the Thumb key, then press ONE key below. It does that one thing and Layer Lock ends. Gray keys just type normally.

Numpad

HOLD Thumb or Num. To keep it on: tap Num (or Layer Lock, then Num). Go home turns it off.

Nav / Media

HOLD Nav. To keep it on: tap Nav (or Layer Lock, then Nav). Go home turns it off.

System

Layer Lock, then B. Do ONE thing, then it closes by itself (or after 5 s). Blank keys do nothing.

The status light uses the same colors (white = Caps Lock).

Word-delete mode

Turn on/off: tap Thumb, then Backspace.
While on: Backspace deletes the previous word, Shift+Backspace the next word, and Nav's Delete deletes the next word. Numpad's Backspace still deletes one character. Starts off after waking or power-on.

Alt codes (Windows)

Hold Thumb (Numpad), hold Alt (its usual spot), type the code on the number keys, let go of Alt. Example: Alt 0176 = °, Alt 0151 = —. If a code moves the cursor instead, tap Num Lock (Esc spot) once and try again.

Flashing new firmware

Plug that half in by USB. Layer Lock, B, then the Flash mode key for that half (Esc spot = left, Backspace spot = right). A drive appears: copy the .uf2 file onto it.

Bluetooth

Quick switch between devices 1 and 2: tap Thumb, then Tab. Devices 1-5 and "Forget": System layer. The status light blinks blue: 1 blink = device 1, 2 = device 2.
